# Implementation plan

The [project hill-climbing goal](active/2026-10-02-yap-project-hill-climb.md) is the single current execution queue for the full roadmap. It defines the objective, progress measures, ordered work, next increment and actual-target qualification. The [supported UI milestone](completed/2026-10-02-hardware-free-product-completion.md) is completed evidence; remaining feature implementation continues in the project goal.

Update that plan when priorities or findings change. Keep implementation and validation results beside the relevant checklist item; do not create a competing plan for each cleanup or UI change.

| Directory | Meaning |
| --- | --- |
| `active/` | Current project goal and execution queue |
| `completed/` | Historical delivery and verification records |
| `archived/` | Superseded plans and decision queues |

Prior CI, MVP validation, decision-queue, and Phase 10 plans are archived. Their accepted contracts and evidence remain available. Archiving does not cancel intended features or requirements. Reconcile unchecked items into the current roadmap and execution plan with source links and explicit dispositions; do not silently discard them.
