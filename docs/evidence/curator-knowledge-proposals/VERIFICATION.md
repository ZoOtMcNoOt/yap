Curator accepts only `explicit-proposal` or `reviewed-student-answer`
submissions. The server re-reads each citation from the authenticated
permission-safe generation. The model returns only one forced `propose` or
`reject` decision; it cannot author proposal content, choose citation authority,
read hidden evidence, activate a generation, or mutate reviewed source truth.
A successful decision may append one immutable noncanonical proposal and its
audits atomically. Invalid evidence, rejection, cancellation, deadline,
provider loss, capacity failure, or audit/write failure publishes no successful
proposal.

result does not prove simultaneous Qwen/Gemma residency,
sustained multi-user capacity, p50/p95/p99 or production SLOs, active-knowledge
