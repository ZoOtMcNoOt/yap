# FLAC recording import

**Owner:** Grant McNatt. **Date:** 2026-10-02. **Scope:** Development working tree; Linux native IO/preparation and Chromium command fixtures, without models.

Native import now accepts FLAC alongside canonical mono PCM16/16 kHz WAV and MP3. FLAC uses the existing Symphonia/canonical preparation owner rather than an external converter. Picker filtering, unsupported-file errors and Transcribe guidance agree. The original remains the source identity; normalized plaintext is temporary.

## Qualification boundary

Chromium uses native-command fixtures and does not decode audio, exercise a native picker or qualify physical Windows playback. Native tests exercise real FLAC decoding, source retention and canonical preparation independently. No ASR, speaker, alignment, enterprise or Windows qualification is claimed. The four-hour output ceiling remains a safety bound rather than an advertised qualified duration.

FLAC’s exact frame count and checksum are checked when provided. Streams without that optional integrity metadata may not reveal every missing ending or modification; no format is claimed to detect all possible damage. M4A/MP4/OGG/WebM remain approved future goals; AAC requires its separate licensing decision.
