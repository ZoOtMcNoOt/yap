# Yap icons

Owner: Grant McNatt. The original vector source is [yap-mark.svg](../../public/yap-mark.svg).

From `desktop`, run `pnpm tauri icon public/yap-mark.svg --output /tmp/yap-icons`.
Copy the existing desktop icon filenames from that directory into this one;
copy `icon.png` to `public/app-icon.png` and `32x32.png` to `public/favicon.png`.
The current desktop release does not use the generated Android/iOS assets.
